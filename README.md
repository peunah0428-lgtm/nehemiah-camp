# 2027 느헤미야 청소년 캠프 참석 조사

2027년 1월 11일(월)~13일(수) · 강화성산예수마을

학생들이 로그인 없이 참석 여부를 응답하는 페이지입니다. 응답은 구글 스프레드시트에 쌓입니다.

## 설정 방법

1. **스프레드시트 만들기**: 구글 드라이브에서 새 스프레드시트를 만듭니다.
2. **Apps Script 연결**: 스프레드시트에서 `확장 프로그램 > Apps Script`를 열고, `apps-script.gs` 내용을 붙여 넣은 뒤 저장합니다.
3. **웹 앱으로 배포**: `배포 > 새 배포 > 유형: 웹 앱`을 선택하고, 실행 사용자는 `나`, 액세스 권한은 `모든 사용자`로 설정해 배포합니다. 나오는 웹 앱 주소(`https://script.google.com/macros/s/.../exec`)를 복사합니다.
4. **주소 넣기**: `index.html`의 `PASTE_APPS_SCRIPT_URL_HERE`를 복사한 주소로 바꿉니다.
5. **페이지 공개**: 저장소 `Settings > Pages`에서 Source를 `main` 브랜치, `/ (root)`로 설정합니다. 몇 분 뒤 `https://peunah0428-lgtm.github.io/nehemiah-camp/` 에서 열립니다.

응답은 스프레드시트의 `응답` 시트에 제출 시각, 이름, 참석 여부, 이유, 기대되는 점 순서로 쌓입니다.
