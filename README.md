# 2027 느헤미야 청소년 캠프 참석 조사

2027년 1월 11일(월)~13일(수) · 강화성산예수마을

학생들이 로그인 없이 참석 여부를 응답하는 페이지입니다. 응답은 구글 스프레드시트에 쌓입니다.

## 연결 상태

- 응답 페이지: https://peunah0428-lgtm.github.io/nehemiah-camp/
- 응답 시트: 구글 드라이브의 `느헤미야 캠프 응답` 스프레드시트, `응답` 탭
- 응답 저장 코드: Apps Script 프로젝트 `느헤미야 캠프 응답 수집` (내용은 `apps-script.gs`와 같음)

## 코드를 고친 뒤 다시 배포하려면

Apps Script에서 `배포 > 배포 관리 > 수정(연필) > 버전: 새 버전 > 배포`를 누르세요. 이렇게 하면 웹 앱 주소가 바뀌지 않아 `index.html`을 고칠 필요가 없습니다.
